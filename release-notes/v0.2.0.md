First public release.

- One sensor with the calories you logged in Yazio today (kcal), updated every 15 minutes, resets at local midnight
- Long-term statistics hold real daily totals (state_class `total` with a daily reset)
- Protein, fat, carbs, your Yazio goal and kcal per meal as attributes
- Read-only. Signs in again when the token expires instead of refreshing it, so the Yazio app on your phone stays signed in

Unofficial: uses Yazio's private API and may break when Yazio changes it.
